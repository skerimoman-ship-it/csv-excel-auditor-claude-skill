# CSV & Excel Data Auditor — Free Claude Skill

Audit and clean any messy CSV or Excel spreadsheet in seconds using Claude Web, Desktop, Cowork, or Claude Code.

## What This Free Skill Catches
- Missing values (>5% nulls) and blank keys
- Exact and near-duplicate records
- Mixed date formats and text-formatted currencies
- Broken Excel formulas (`#REF!`, `#DIV/0!`, `#N/A`)
- Embedded subtotal/total rows that cause double-counting
- Assigns a 0–100 Data Readiness Score before you run analysis

## 3-Minute Setup
1. Download `SKILL.md` from this repo.
2. In Claude, open **Customize > Skills > Add Skill** and upload `SKILL.md`.
3. Test it right away by uploading `sample_messy_sales.csv` and asking: *"Audit this spreadsheet for data quality issues."*
